# 🪸 Polyp Framework

**The universal scaffold for AI coding agents.**

One repo structure. Every platform. Quality-gated development. Agent-vs-agent benchmarks.

---

## What is Polyp?

Polyp is a stack-agnostic meta-framework that solves three problems:

1. **Platform fragmentation**: Every AI coding agent (Claude Code, Cursor, Windsurf, Aider, Copilot, Cline, Codex, Devin, Amazon Q, Continue.dev, Replit) reads rules from different files in different formats. Polyp maintains a single source of truth (`AGENTS.md`) and syncs to all platforms.

2. **Quality drift**: AI agents wander off-task, skip tests, make drive-by refactors, and produce inconsistent commit messages. Polyp enforces a structured development lifecycle (the Strobilation Pattern) with quality gates at every phase.

3. **No way to compare agents**: Which agent writes better code? Which follows instructions more faithfully? Polyp includes an Elo-style benchmarking framework that ranks agents across diverse task types using the same statistical methodology as Chatbot Arena.

## Quick Start

```bash
# Clone the scaffold
git clone https://github.com/your-org/polyp-framework my-project
cd my-project

# Initialize your project (any AI agent can drive this)
# Open in your preferred agent and say:
# "Read .agentile/init/INIT.md and walk me through project initialization"

# Or manually:
cat .agentile/init/INIT.md  # review the questionnaire
# Fill in PROJECT_DNA.yaml with your answers
# Run sync to distribute rules
node .agentile/sync.mjs

# Validate everything is set up correctly
node .agentile/validate.mjs
```

## Naming Convention: The Medusa Paradigm

Polyp uses cnidarian biology as its naming convention, derived from ["The Medusa Paradigm"](docs/medusa-paradigm.md) research framework on biomimetic distributed systems design.

| Phase | Biology | Software |
|-------|---------|----------|
| 🌱 **Planula** | Larva seeking substrate | Write the spec, create the story |
| 🪸 **Polyp** | Sessile stage, cloning | Write failing tests (Red phase) |
| 🔪 **Strobila** | Segmenting into units | Minimal implementation (Green phase) |
| 🪼 **Ephyra** | Juvenile swimming free | Refactor while tests stay green |
| 🌊 **Medusa** | Mature adult | Ship to production |

## Benchmarking Agents

Run the same task on multiple agents, then compare:

```bash
# 1. Give task 001 to Agent A (e.g., Claude Code)
#    Agent reads .agentile/benchmarks/tasks/001-greenfield.md
#    Agent works in an isolated workspace

# 2. Score Agent A's output
node .agentile/benchmarks/scoring/score.mjs \
  --task 001 --agent claude-code \
  --workspace ./results/claude-code/001/workspace

# 3. Repeat for Agent B (e.g., Cursor)
# 4. Recalculate Elo ratings
node .agentile/benchmarks/scoring/elo.mjs --recalculate
```

The Elo system uses Bradley-Terry maximum likelihood estimation with 1,000 bootstrap permutations for confidence intervals — the same methodology as LMArena's Chatbot Arena.

## Contributing

This is a V0 scaffold. High-impact areas for contribution:

- **More benchmark tasks**: Especially security, performance, and documentation categories
- **Language-specific scoring**: Integration with SonarQube, CodeClimate, Sourcery
- **Architecture fitness functions**: ArchUnit/Madge integration for the architecture dimension
- **Platform adapters**: Better handling of platform-specific features (Cursor's glob matching, Windsurf's char limits)
- **CLI tool**: `npx polyp init` that wraps the INIT.md questionnaire
